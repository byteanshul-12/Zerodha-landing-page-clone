

# Zerodha Landing Page Clone

A pixel-perfect clone of the Zerodha landing page built using pure HTML and CSS. This project demonstrates front-end development skills by recreating the design and layout 



##  Built With

- **HTML5** - Semantic markup
- **CSS3** - Styling and layout
- **Flexbox/Grid** - Responsive layout design

##  Features

- Clean and modern UI matching Zerodha's design language
- Smooth hover effects and transitions
- Semantic HTML structure
- Cross-browser compatible
- Optimized for performance

##  Prerequisites

No special prerequisites needed! Just a web browser to view the project.

##  Installation

1. Clone the repository
   ```bash
   git clone https://github.com/yourusername/zerodha-clone.git
   ```

2. Navigate to the project directory
   ```bash
   cd zerodha-clone
   ```

3. Open `index.html` in your browser
   ```bash
   # On Windows
   start index.html
   
   # On macOS
   open index.html
   
   # On Linux
   xdg-open index.html
   ```


##  Browser Support

- Chrome (latest)
- Firefox (latest)
- Safari (latest)
- Edge (latest)
